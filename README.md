# Lapis Terminal

Reusable Rust terminal sessions, a Tauri plugin and a layout-neutral Svelte
viewport. Hosts supply admitted targets and compose docks, tabs or panes.
Runtime processes require no Node or Deno installation.

See [usage](docs/usage.md) and the [specification](spec/src/current/index.md).
Initial native qualification targets macOS ARM64; the milestone ledger records
actual acceptance. No sibling application is modified or required to build.
